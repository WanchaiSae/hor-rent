# Room Rent (DormFlow)

ระบบจัดการหอพักสำหรับดูแลห้องพัก ผู้เช่า สัญญา และรายการเรียกเก็บเงิน พัฒนาด้วย Next.js และ PostgreSQL

> **สถานะ: อยู่ระหว่างพัฒนา** — ระบบมีหน้าเว็บและ API สำหรับจัดการข้อมูลหลักแล้ว แต่ยังไม่ใช่ระบบที่พร้อมใช้งานจริงครบทุกด้าน

## ระบบทำอะไรได้บ้าง

- **ภาพรวม:** ดูจำนวนห้องทั้งหมด ห้องว่าง ผู้เช่าปัจจุบัน รายรับเดือนนี้ และใบแจ้งหนี้ที่ยังไม่ชำระ
- **หอพักและห้องพัก:** เพิ่ม แก้ไข และลบข้อมูลหอพักและห้อง พร้อมระบุค่าเช่าและสถานะห้อง
- **ผู้เช่าและสัญญา:** จัดการข้อมูลผู้เช่า สัญญารายวันหรือรายเดือน และผู้เช่าที่เกี่ยวข้องกับแต่ละสัญญา
- **ใบแจ้งหนี้:** บันทึกยอดเรียกเก็บและรายการย่อย เช่น ค่าเช่า ค่าน้ำ หรือค่าไฟ พร้อมติดตามสถานะชำระ
- **รายรับและรายจ่าย:** บันทึกรายการธุรกรรมและจัดหมวดหมู่ทางการเงิน
- **ค้นหาและจัดการข้อมูล:** ค้นหาในหน้าที่เปิดอยู่ เพิ่ม แก้ไข หรือลบรายการได้ และเชื่อมต่อข้อมูลกับ PostgreSQL

หน้าเว็บออกแบบให้ใช้ได้ทั้งบนคอมพิวเตอร์และโทรศัพท์ ส่วนร้านค้า/ซัพพลายเออร์ งานซักผ้าและตู้กดน้ำ รวมถึงงานซ่อมบำรุง **ยังไม่มีระบบรองรับ** ในตอนนี้

## เทคโนโลยี

- Next.js, React และ TypeScript
- PostgreSQL 16 สำหรับจัดเก็บข้อมูล
- Docker Compose สำหรับเปิด PostgreSQL และ pgAdmin
- Bun สำหรับติดตั้งแพ็กเกจและรันคำสั่งของเว็บ

## เริ่มต้นใช้งาน

ต้องติดตั้ง [Docker](https://www.docker.com/) และ [Bun](https://bun.sh/) ก่อน

1. ที่โฟลเดอร์หลักของโปรเจกต์ คัดลอก `.env.example` เป็น `.env`
2. ใน `.env` ตั้งค่า `POSTGRES_PASSWORD` และรหัสผ่าน pgAdmin (`PGADMIN_DEFAULT_EMAIL` และ `PGADMIN_DEFAULT_PASSWORD`) จากนั้นกำหนด `DATABASE_URL` ให้ใช้รหัสผ่าน PostgreSQL เดียวกัน เช่น:

   ```env
   DATABASE_URL=postgresql://postgres:your-password@localhost:5432/dorm_management
   ```

3. เปิดฐานข้อมูลจากโฟลเดอร์หลัก:

   ```bash
   docker compose up -d postgres
   ```

4. เข้าโฟลเดอร์ `web` ติดตั้งแพ็กเกจ สร้างตาราง และเริ่มเว็บ:

   ```bash
   cd web
   bun install
   bun run db:migrate
   bun run dev
   ```

5. เปิด [http://localhost:3000](http://localhost:3000)

Migration จะบันทึกเวอร์ชันที่รันแล้ว จึงสั่ง `bun run db:migrate` ซ้ำได้โดยไม่รัน migration เดิมอีกครั้ง

หากต้องการจัดการฐานข้อมูลผ่าน pgAdmin ให้เปิดบริการด้วย `docker compose up -d` จากโฟลเดอร์หลัก แล้วเข้า [http://localhost:5050](http://localhost:5050)

## API

- `GET /api/health` ตรวจสอบการเชื่อมต่อฐานข้อมูล
- API สำหรับข้อมูลหอพัก ห้อง ผู้เช่า สัญญา ผู้เช่าในสัญญา หมวดหมู่ธุรกรรม รายรับ-รายจ่าย ใบแจ้งหนี้ และรายการในใบแจ้งหนี้
- ทุก resource รองรับ `GET` และ `POST` ที่ `/api/{resource}`; ใช้ `GET`, `PATCH` และ `DELETE` ที่ `/api/{resource}/{id}` สำหรับรายการเดียว
- รายการรองรับการแบ่งหน้าด้วย `?limit=50&offset=0` (สูงสุด 100 รายการต่อครั้ง) และห้องพักกรองตามหอพักได้ด้วย `?dormitoryId=1`

ตัวอย่างเพิ่มหอพัก:

```http
POST /api/dormitories
Content-Type: application/json

{"code":"A","name":"หอพัก A"}
```

API ส่งข้อมูลเมื่อสำเร็จไว้ใน `data`; ข้อมูลไม่ถูกต้องตอบ `400`, ไม่พบรายการตอบ `404` และข้อมูลซ้ำหรือข้อจำกัดความสัมพันธ์ตอบ `409`
